## 二、前端探头与耦合的核心问题

### 问题 1:没有电流探头,Phase 0 无法启动

**现状**:候选人手头**完全没有**任何 RF 电流探头(无 Tekbox / Fischer / Pearson 之类)。

**影响**:
- Phase 0 验证电源线传导泄漏需要 CT 才能采集到信号
- 没有 CT → 没有 Phase 0 → 没有可行性数据 → 项目无法启动

**待向学长求证**:
- (a) 实验室是否有现成的宽带 CT?具体型号?
- (b) 如果没有,项目启动预算能否支持采购 Tekbox TBCP2-1000(~¥4,500)?
- (c) 是否有借用渠道(其他实验室、合作方)?

### 问题 2:自研 CT 在 1 周提案窗口内不可行

**评估结论**(已在仓库 `coupling_refined_analysis.md` 中详细论证):
- 磁芯(Fair-Rite #43 + #75 复合)采购周期 7-15 天
- 绕组工艺迭代需要 3-4 次实验,每次 0.5 天
- VNA 验证 + 调试 1 天
- **完整自研周期 2-3 周**,且没有实验室环境根本启动不了

**所以**:自研 CT 设计分析保留作为 Phase 2 学术探索方向,不作为 Phase 0 主路径。

### 问题 3:信号水平未知 → 链路预算无法收敛

**现状**:
- 论文 EM Eye 只给了**空气场景**信号水平(近场磁探头 ~-80 dBm)
- 电源线传导场景的信号水平**论文未公开**
- 我们的链路预算基于假设值:
  - I_CM ~ 1-10 μA(估计)
  - 经 CT(-20 dB)后 ~-70 dBm
  - LNA +28 dB + AD9363 内部 +30 dB
  - 留 35 dB 余量

**问题**:**如果实际信号弱 20-30 dB**,LNA 增益不够,需要加 PGA-103+ 第三级。

**这就是第一个必问的问题**(Q1)。

### 问题 4:耦合拓扑选择 — CM 还是 DM?

**现状**:我们的方案假设泄漏在电源线上以**共模(CM)**为主:
- L+N 同方向穿过 CT 磁芯
- DM(50Hz 工频)完全抵消
- CM(MIPI 数据辐射)加倍叠加

**但**:论文没明确说他们的验证拓扑。如果他们发现 DM 通道在某些 MIPI 谐波频点上也有显著耦合,我们的工装设计需要调整。

**这就是第二个核心问题**(Q3)。

### 问题 5:隔离/保护链是否过度简化?

**现状**:
- 简化方案:夹式 CT(电气隔离) + 设备 USB 供电(不接市电) + 信号侧只有 TVS + DC 隔直 + HPF
- 删除了:GDT、MOV、共模扼流圈、X1/Y2 安全电容
- 总元件成本从原方案 ¥80 降到 ¥11

**风险**:如果学长经验上认为简化太激进(比如电源线高频瞬态可能产生破坏性能量),需要恢复部分元件。

### 问题 6:LNA 频段是否完全覆盖

**现状**:
- ERA-4SM+ 单芯片规格 DC – 4 GHz,我们测过 5.6 MHz – 3 GHz 平坦 ±3 dB
- 工作目标频段 100 MHz – 1 GHz,**完全覆盖**
- 但 200-700 MHz(EM Eye Table II 多数目标)增益略高,平坦度可能 ±1-2 dB

**判断**:LNA 频段没有问题,但具体的 P1dB、IP3 等参数没实测,**链路预算的 IIP3 部分是基于数据手册值**(IIP3 +20 dBm 输入端)。

### 问题 7:阻抗匹配未充分验证

**现状**:整条信号链假设 50Ω 系统,但:
- CT 二次侧端接需要严格 50Ω(Phase 0 时 VNA 实测验证)
- HPF/BPF 通带阻抗变化(已有教科书设计公式,未实物验证)
- LDSDR AD9363 输入端可能不完全是 50Ω(数据手册说典型 50Ω)

**风险**:级联失配可能导致 5-10 dB 额外损耗,但**可以通过 π 型衰减器调整**(已在设计中预留)。

> - 简化保护链 → 无 GDT/MOV,只有 TVS + DC 隔直 + 30 MHz HPF(夹式 CT 已电气隔离 + 设备 USB 供电)
>
> **这架构有明显的坑吗?**"

**追问准备**(根据学长指出的"坑"调整方向):
- 说 2RX 多频段没必要:🟡 那 Phase 1 改为单 RX
- 说要回 CM4:🟡 解释 Ethernet 带宽够,愿意听理由
- 说保护链太简化:🟡 列出他们的标准做法,补足

#### 坑题 2:"你说的复合磁芯 CT,L_m 是多少?"

```
那部分是我桌面研究阶段做的工程估算,基于 Fair-Rite 材质手册的 
μᵣ 数据,**没有实际制作过 CT**。Phase 0 第 1 周如果需要会按这个
方案搭一个,VNA 实测后调整。但我现在的 Phase 0 主路径是用商用 CT

```

#### 坑题 3:"既然没做仿真,你怎么知道方案能行?"

```
论文已经证明攻击物理上成立(空气场景),我的方案主要是工程适配。

能不能行的关键是电源线 vs 空气的信号水平比例 — 这正是我第一个问题。

如果电源线信号弱不到 20 dB 以内,我有信心 +28 dB LNA + AD9363 内部 
30 dB 增益能覆盖。如果弱 30 dB+,需要重新评估 — 这种情况下我会建议
延长 LNA 增益或换更高灵敏度的耦合方式。
```

#### 坑题 5:"为什么删 CM4 是好选择?Ethernet 直连 PC 没问题吗?"

```
LDSDR 千兆 Ethernet 实际吞吐 800 Mbps,8 MSPS × 2 通道 × 12 bit × 2 
= 384 Mbps,占用 48%,余量充足。

而 CM4 通过 USB OTG 接 Pluto 时,实际带宽受 USB 2.0 限制只有 
30 MB/s = 240 Mbps,反而是瓶颈。

删 CM4 后:节省 ¥1000,形态紧凑 100×60×30mm,LDSDR Zynq PS 自带 
Linux 跑得动 GNURadio,完全够用。
```

#### 坑题 6:"为什么删 GDT/MOV 这些保护元件?"

```
两层原因:

1. 设备 USB 供电(不接市电),没有市电雷击/浪涌通过电源线侵入的
   物理路径。
   
2. 信号侧通过夹式 CT 已经电气隔离(磁耦合),CT 一次侧到二次侧没有
   电气连接,GDT/MOV 该保护的威胁场景不存在。

但我保留了 TVS(±5V 钳位)处理 ESD 和 DUT 启动瞬态,这是真实存在
的威胁。这个判断和 Pluto/LDSDR 自身的 SMA 接口设计是一致的 — 它们
也只有 TVS,没有 GDT/MOV。
```

### 关键时间锚点

- **第 25 分钟前必须问完 Q1 + Q2** — 这两个问题不答上来,提案就没法收尾
- **如果学长开始问你回答时间超过 15 分钟** — 委婉打断:"学长不好意思,我还有几个具体问题想趁这次机会请教..."
- **会议最后 5 分钟必须确认下一步** — 不能模糊收尾

## 六、关键策略与禁忌

### ✅ 必须做到

1. **诚实** — 不会的就说不会,"我没做仿真" / "我没实测 CT" / "我 RF 深度不够" → 这些都是加分项
2. **带方案** — 不空手讨论,每个问题都有具体型号、数字、决策
3. **GitHub repo 准备好** — 浏览器开着 https://github.com/stongry/powerline-emeye-proposal
4. **追问** — 每个问题听完答案要追问"这意味着我应该 X 还是 Y"
5. **笔记** — 准备纸笔或开一个空 markdown 文件,实时记录学长答案

### ❌ 千万不要

1. **装作什么都懂** — 比大方承认更糟
2. **没准备就开会** — 显得不重视
3. **抢话** — 让学长充分说,你听
4. **过度推销自己** — 让 BYO + 项目经验自己说话
5. **承诺过头** — "我能 4 周搞定 Phase 0" 是负 EV,会被记恨
6. **泄漏过多细节** — 私有仓库等学长主动问再分享,不要主动塞过去

- [ ] 打开 GitHub repo:https://github.com/stongry/powerline-emeye-proposal
