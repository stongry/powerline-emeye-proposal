## 一、架构最终确认:设备与市电完全解耦

### 关键架构决策(2026-05-13 更新)

**设备本体由 USB 5V 供电**(移动电源 / USB 充电器 / 笔记本 / 车载 USB),**整个采集系统不接触市电**。唯一与市电"关联"的元件是夹式 CT,但 CT 是**电气隔离**的磁耦合元件,一次侧(电源线)与二次侧(信号输出)无电气连接。

### 这个简化的三层意义

#### 安全性飞跃
- 设备内部完全无市电 → 触电风险归零
- 不需要 IEC 61010 安全认证(那是涉及市电的设备才需要)
- 不需要 EMC Class B 严苛认证
- 只需要按"USB 供电信息技术设备"做基础合规

#### BOM 简化
- 删除内部 AC-DC 适配器(Mean Well IRM-10-5 ¥80)
- 删除信号侧 GDT / MOV / 共模扼流圈(¥60)
- 删除 Phase 0 隔离变压器需求(¥1,200)
- 新增 USB-C 接口 + ESD 保护(¥30)
- **净省 ¥1,310**

#### 现场部署能力
- 充电宝供电 → 完全便携
- 笔记本 USB 直供 → 无需另插电
- 形态可压缩到 100×60×30 mm

### 两条路径的最终定义

#### 路径 A — 设备供电(完全独立于市电)
```
USB-C 5V/3A → CM4 内部稳压 → Pluto USB OTG → LNA 偏置
              └─ 模拟域 LDO(TPS7A47)→ LNA Vcc
```

#### 路径 B — 信号路径(电气隔离,无市电接触)
```
DUT 电源线 ╳ 夹式 CT 磁芯 → 二次侧 → TVS → HPF → LNA → Pluto
```

### 这一决策让 Phase 2 演进路线更清晰

Phase 1 = USB 供电便携式(本提案聚焦)
Phase 2 = 插头适配式(才需要完整 GDT/MOV 链 + IEC 61010 认证)

Phase 1 验证完攻击可行性后,Phase 2 才是"形态优化"工作。**不要把 Phase 2 的复杂性压到 Phase 1**。

## 三、耦合 — 宽带夹式 CT 设计

这是整个项目最难的硬件单元。

### 3.0 物理原理(快速温习)

CT 本质是一个**变压器**,工作在电流模式下:

```
一次侧电流 I_p 流过 → 在磁芯中产生交变磁通 Φ → 二次侧 N 匝绕组感应电压
                  (Ampère 定律)              (Faraday 定律)
```

**理想 CT 方程**(电流变压器关系):

```
V_secondary = R_load × I_primary / N
```

5 匝绕组、50Ω 端接、目标共模电流 1 μA → V₂ = 10 μV(电压级 -97 dBV ≈ -87 dBm)。这就是 LNA +28 dB 增益的必要性来源。

### 3.0.1 CT 的三段频响

| 段 | 决定因素 | 公式 |
|---|---|---|
| **低频拐点 f_L** | 磁化电感 L_m | f_L = R_load / (2π · L_m) |
| **平坦区 f_L → f_H** | 磁芯磁导率 μᵣ | 由材质决定 |
| **高频拐点 f_H** | 漏感 L_l 与匝间电容 C_w | f_H = 1 / (2π · √(L_l · C_w)) |

**关键洞察**:
- 降 f_L 用高 μᵣ 磁材(L_m 增大)
- 升 f_H 减少匝数(L_l 减小)+ 紧绕减少 C_w + 低介电常数线材
- 两者相互冲突 → **必须复合磁芯**

### 3.0.2 共模 vs 差模 — EM Eye 攻击的核心

**电源线侧信道泄漏主要是共模电流**,差模是 50 Hz 工频本身,不是目标。

| 模式 | 来源 | 频率范围 | 我们要 |
|---|---|---|---|
| **差模(DM)** | 设备工作电流 | 50/60 Hz + 谐波 | ❌ 干扰源 |
| **共模(CM)** | MIPI 数据辐射泄漏 | 100 MHz – 1 GHz | ✅ **目标信号** |

#### CT 一次侧穿芯方式决定测什么

```
方案 A — 只穿 L 线:
CT 看到 = I_DM + I_CM/2  →  混合,无法区分

方案 B — L+N 同方向穿过(我们要的):
CT 看到 = (I_DM + I_CM) + (-I_DM + I_CM) = 2 · I_CM
                                          ↑
                                     差模完全抵消,共模加倍!

方案 C — L 和 N 反方向穿过(差模噪声测试用):
CT 看到 = 2 · I_DM  →  这不是我们要的
```

**结论**:**夹式 CT 必须把 L 和 N 同方向穿过磁芯**
- 差模(50 Hz 工频):理论 ∞ dB 抑制,实际 30-40 dB(因机械不对称)
- 共模(EM Eye 泄漏):加倍叠加,+6 dB 灵敏度增益

### 3.0.3 三孔插头(L/N/PE)处理

| 情况 | CT 看到 | 评价 |
|---|---|---|
| L + N 同时穿过(PE 在外) | 2 · I_CM | ✅ 推荐 |
| L + N + PE 全穿过 | 0(三线 CM 之和为 0) | ❌ 错误,信号消失 |
| 只 PE 穿过 | I_CM | 备选验证手段 |

**工程实施方案** — 定制 2 芯延长线:

```
DUT 插头 ──┬── L ────── L → 墙插
           ├── N ── L+N 同向穿过 CT → 墙插
           └── PE ─────────────── PE → 墙插
                     ↑
                CT 夹这一段
```

用户体验:像普通插线板,但自动保证 L+N 同向穿过 CT,PE 独立走线。

### 3.1 关键设计参数

| 参数 | 目标 | 备选 | 说明 |
|---|---|---|---|
| **-3 dB 带宽下限** | 1 MHz | 500 kHz | 不需要更低(目标 ≥155 MHz) |
| **-3 dB 带宽上限** | 1 GHz | 500 MHz | 1 GHz 难,500 MHz 足够覆盖 Table II 7/12 设备 |
| **插损平台** | -30 dB | -45 dB | 越低越好,但实物难 < -25 dB |
| **平坦度** | ±3 dB | ±5 dB | 跨工作带 |
| **耐压** | 250 V AC 50 Hz | — | 一次侧穿芯,标称耐压由磁芯绝缘决定 |
| **物理尺寸** | OD<25 mm | OD<40 mm | 适配紧凑外壳 |
| **形态** | **穿芯式**(不分体) | 分体钳形(Phase 2) | 分体钳形高频性能严重下降 |

### 3.2 磁芯选型 — 复合材质串叠

单一磁材无法做到 1 MHz – 1 GHz 平响,**用 2 个不同材质叠加**:

```
        ╭─────────╮  顶层:Fair-Rite 2675102002
        │ ████████│  材质 #75(Nano-crystalline),μᵣ ~ 5000
        │  ▒ ▒ ▒  │  覆盖低端 1-50 MHz
        │ ████████│
        ├─────────┤
        │ ████████│  底层:Fair-Rite 2643000201
        │  ▒ ▒ ▒  │  材质 #43(NiZn),μᵣ ~ 800
        │ ████████│  覆盖中段 50 MHz – 500 MHz
        ╰─────────╯  
        外径 12.7 mm,内径 7.9 mm,各 H=6.35 mm
        合计高度 12.7 mm
```

**复合堆叠**的原理:

两个磁材的频响曲线**互补叠加**,有效频响 = 两段并联响应。

- 1 MHz – 50 MHz 段 #75 主导
- 50 – 500 MHz 段 #43 主导
- \>500 MHz 段已经进入磁芯非主响应区,只能靠"空气芯效应"(漏感主导)勉强保留耦合

**BOM 成本**:¥60(两片磁芯)

### 3.3 绕组设计

```
┌─────────────────────────────────────────┐
│  绕组方式:5 匝单层 Teflon 同轴内导体    │
│                                          │
│  线材选择(关键):                       │
│  - RG-178 内导体(剥外层,只用内导体    │
│    + Teflon 内绝缘)                      │
│  - 介电常数 εr=2.1,匝间分布电容低       │
│  - 直径 ~0.6mm,绕组紧凑                 │
│                                          │
│  绕法:                                   │
│  - 单层均匀分布(360° 间隔均匀)         │
│  - 起头和收尾点距离 ≥1/4 周长(防止     │
│    自感互耦)                             │
│  - 不要扎在一起!                         │
└─────────────────────────────────────────┘
```

**为什么是 5 匝**:

| 匝数 | 灵敏度 | 上限频率 | 评价 |
|---|---|---|---|
| 1-2 匝 | 低 | 高 | 信号太弱 |
| 5-7 匝 | 中 | 500 MHz – 1 GHz | ✅ **甜区** |
| >10 匝 | 高 | 100-200 MHz | 自谐振点太低 |

5-7 匝是经验甜区:匝间分布电容 Cₚ 和漏感 Lₗ 形成的自谐振点通常落在 500 MHz – 1 GHz。

### 3.4 灵敏度计算

二次侧电压:

```
V₂ = (Iₚ × Z_load) / N
```

- N = 5 匝
- Z_load = 50 Ω
- 假设 Iₚ = 1 mA(目标频段共模电流):V₂ = 10 mV = -27 dBm
- 实际目标信号 1-100 μA 量级:V₂ = 0.01-1 mV = **-67 ~ -47 dBm**

这给 LNA 提供了估算的输入功率范围。

### 3.5 输出端接 + 屏蔽

```
[CT 二次绕组] ──短引线── [50Ω SMD 电阻 0805] ── SMA 母座
                  │
                  └──→ 同时焊在 PCB 上
                       (引线长度 < 5 mm)
```

**关键点**:
- 50Ω 端接电阻**就近**焊在 CT 引脚根部,不要拉长线再接
- 长引线 = 反射 = 高频驻波 = 性能下降
- 选 0805 薄膜电阻(±1%),寄生电感 < 0.5 nH

**屏蔽外罩**:
- 整个 CT 装在**金属罩**(铜或铝)内,罩开两个孔让电源线穿过
- 罩接信号地(单点接地)
- 作用:屏蔽外部空间辐射对 CT 的串扰(否则空间 WiFi/GSM 直接耦合进绕组)

### 3.55 实际装配步骤(自研最小 CT,1-2 天可完成)

```
步骤 1:复合磁芯准备
  - 取 Fair-Rite 2675102002 (#75 nano) ×1
  - 取 Fair-Rite 2643000201 (#43 NiZn)  ×1
  - 两片同心叠加,用聚酰亚胺胶带固定

步骤 2:绕组准备
  - RG-178 同轴线剥外屏蔽和外皮,只保留内导体 + Teflon 内绝缘
  - 长度约 25 cm

步骤 3:绕组
  - 5 匝,单层均匀分布,360°间隔均匀
  - 起头和收尾在磁芯同一侧,但距离 ≥ 1/4 周长(防自感性耦合)
  - 匝间留 1-2 mm 间隙,不要扎在一起

步骤 4:端接
  - 二次侧两端引线焊到 PCB 焊盘
  - 0805 50Ω 薄膜电阻就近焊在 PCB(引线 ≤ 5 mm)
  - SMA 母座 PCB 直焊

步骤 5:屏蔽
  - 整个 CT 装在铜罩里(开孔让 L+N 二线穿过)
  - 铜罩单点接地到 PCB 模拟地

步骤 6:VNA 验证
  - S21 测试:1 MHz – 3 GHz 扫频
  - 通过判据:
    * 1 MHz – 500 MHz 平坦,插损 -25 dB ± 5 dB
    * >500 MHz 缓慢下降到 -35 dB
    * 自谐振点 > 800 MHz(凸起或凹陷高于此频)
```

### 3.56 关键风险与对策

| 风险 | 触发条件 | 对策 |
|---|---|---|
| 复合磁芯叠加效果不如预期 | 50-100 MHz 段实测频响凹陷 | 调整磁芯组合(2片 #43 + 1片 #75 等迭代) |
| 自谐振点过低(<500 MHz) | 5 匝 Cₚ 偏大 | 改为 3-4 匝(损失灵敏度换带宽) |
| DM 抑制不足(<20 dB) | 两根线未真正同向同位置 | 改用定制 2 芯延长线方案,机械保证对齐 |
| 屏蔽不足,空间 WiFi 干扰 | 铜罩接缝大 | 加 EMI 衬垫或整体冲压金属盒 |

### 3.6 预期性能(基于经验估算,需 VNA 验证)

| 频率 | 预期插损 | 备注 |
|---|---|---|
| 1 MHz | -25 dB | #75 磁芯主导 |
| 10 MHz | -22 dB | #75 工作峰区 |
| 100 MHz | -23 dB | #43 主导 |
| 500 MHz | -25 dB | #43 衰减开始 |
| 1 GHz | -30 ~ -35 dB | 漏感主导,边缘可用 |
| 2 GHz | -40 ~ -50 dB | 性能恶化,不可用 |

**核心断言**:**1 MHz – 800 MHz 可用,1 GHz 边缘可用,>1 GHz 失效**。这覆盖 EM Eye Table II 中**至少 9/12 设备**的目标频点。

## 四、信号侧保护链(简化版)

USB 供电架构后,信号路径上的保护元件大幅减少。**每一个删除都有具体物理依据**,每一个保留都有工程理由。

### 4.1 删除了什么 + 为什么

| 元件 | 原用途 | 删除依据 |
|---|---|---|
| GDT(气体放电管) | 防雷击 | 设备不接市电,雷击无法通过 CT 二次侧侵入(CT 一次/二次电气隔离) |
| MOV(压敏电阻) | 工频过压钳位 | 同上 |
| X1/Y2 安全电容 | 工频隔离 | CT 已电气隔离,不需再加 |
| 共模扼流圈(信号侧) | 共模噪声抑制 | ⚠️ **我们要的就是共模信号,扼流圈会扼掉它,绝对不能加** |
| 1:1 隔离变压器 | 调试安全 | 设备 USB 供电,调试时本身不接墙插,不需要 |

> ⚠️ **特别强调**:共模扼流圈在信号路径上是大忌。Day 1 初稿决策 3 那条链是抄了"市电入口标准设计",在本项目里要反着来 —— 共模就是信号本体。

### 4.2 简化后的链路

```
[CT 二次侧 SMA] → [低 C TVS] → [DC 隔直] → [LC HPF Stage 1] → [LNA]
                     │             │              │
                  ESD/瞬态       阻 DC,        滤工频残余 +
                  钳位          通 RF          AM/SMPS 噪声
```

### 4.3 元件 1: 低 C TVS(必备)

**为什么必须用低电容 TVS,不能用普通 TVS**:

| 类型 | 寄生电容 | @ 1 GHz 阻抗 | 评价 |
|---|---|---|---|
| 普通 TVS(SMAJ12A) | ~200 pF | 0.8 Ω | ❌ **几乎短路到地,信号被吃掉** |
| RF 专用 TVS(CDSOT23-T05LC) | <1 pF | 160 Ω | ✅ 高频透明 |

**选型详情:Bourns CDSOT23-T05LC**

| 参数 | 值 | 评价 |
|---|---|---|
| 反向工作电压 V_RWM | ±5 V | 远大于 LNA 安全输入(典型 0.1 Vpp = ±0.05 V) |
| 钳位电压 V_C @ 1 A | ±8 V | 任何 >8 V 瞬态都被钳到 8 V |
| ESD 防护 | ±15 kV(空气放电) | 工业级 |
| 寄生电容 | <1 pF @ 1 GHz | RF 透明 |
| 响应时间 | <1 ns | 比手部 ESD 上升沿快 |
| 封装 | SOT-23 | 微型 |

**保护威胁场景**:
1. 用户拔插 SMA 时手指 ESD ±10 kV
2. DUT 通断电瞬间通过 CT 感应的高频突变
3. DUT 故障(如 SMPS 击穿)产生瞬态尖峰

### 4.4 元件 2: DC 隔直(必备)

**选型:Murata GRM18 NP0 1 nF / 100 V**

**容抗 vs 频率**:

| 频率 | X_C = 1/(2πfC) | 在 50Ω 系统中的损耗 |
|---|---|---|
| 50 Hz | 3.18 MΩ | 完全阻断(0 dB 通过) |
| 1 kHz | 159 kΩ | 完全阻断 |
| 1 MHz | 159 Ω | -8 dB |
| **30 MHz**(HPF 截止) | **5.3 Ω** | **-0.4 dB**(可忽略) |
| 100 MHz | 1.6 Ω | -0.1 dB(透明) |
| 1 GHz | 0.16 Ω | -0.01 dB(完全透明) |

**为什么用 NP0/C0G 介质而不是 X7R**:
- NP0 温度系数极小(±30 ppm/°C),跨环境无漂移
- Q 值高,损耗低
- 无压电效应,不因机械振动产生噪声
- 价格只贵 1-2 倍,值得

**为什么不用更大的电容(10 nF / 100 nF)**:
- 目标频段从 100 MHz 起,1 nF 已经透明
- 大电容寄生电感大,在 GHz 段反而变坏
- 1 nF 是甜区

### 4.5 元件 3: LC HPF(Stage 1,必备)

详见 §5.1,这里只说在保护链中的角色:
- 滤 50 Hz 工频残余(CT DM 抑制后仍可能有 -40 dBm 残留)
- 滤 AM 广播(530 kHz – 1.7 MHz)和 FM 低端
- 滤室内 SMPS 传导 EMI(<30 MHz)

通带损耗 <1 dB,几乎不付代价。

### 4.6 ESD 放电通路设计(关键)

```
   ESD 入口(SMA 中心针 或 接触金属壳)
        │
        ▼
   [低 C TVS] ─── 短路到 PCB 模拟地(引线 ≤ 5 mm)
        │
        ▼
   PCB 模拟地平面(L2 全填铜,不间断)
        │
        ▼ 单点接地(Star Ground @ LNA-SDR 接口)
   PCB 数字地平面
        │
        ▼
   USB-C 屏蔽外壳(机壳地)
        │
        ▼
   USB 线缆屏蔽 → 电源端释放
```

**强制设计规则**:
- TVS 距离 SMA ≤ 5 mm,引线越短越好(寄生电感拖慢响应)
- PCB 模拟地必须是完整连续填铜面(L2 层),不能被切断
- 模拟地和数字地**单点连接**(在 LNA 与 SDR 接口附近)
- USB 屏蔽接到机壳地,机壳通过 RC 串联到 PCB 地(防止 USB 端噪声反耦合)

## 五、滤波 — 两阶段策略

### 5.1 Stage 1: LC HPF(永远在线)

**目的**:滤掉 AM 广播(<2 MHz)+ FM 广播低端 + 室内 SMPS 传导 EMI(<30 MHz)

**拓扑**:**4 阶 Butterworth HPF, 50Ω, fc=30 MHz**

```
   ┌── L2 ──┬── L4 ──┐
50Ω        │        │     50Ω
in ─[C1]─ GND ─[C3]─GND ─ out
```

**元件清单**:

| 位号 | 值 | 型号 | 说明 |
|---|---|---|---|
| C1 | 150 pF | Murata GRM1885C2A151JA01 | NP0 |
| L2 | 150 nH | Coilcraft 0603HP-151X | Q>50 @ 100MHz |
| C3 | 56 pF | Murata GRM1885C2A560JA01 | NP0 |
| L4 | 330 nH | Coilcraft 0603HP-331X | — |

**理论性能**:

| 频率 | 损耗 |
|---|---|
| 50 Hz | -200 dB |
| 1 MHz | -100 dB |
| 10 MHz | -25 dB |
| 30 MHz | -3 dB (截止) |
| 100 MHz | -0.3 dB |
| 1 GHz | -0.1 dB |

**通带损耗 < 1 dB**,这是 Stage 1 必选的关键理由 —— 几乎不付代价就拿到 100 dB 的低频抑制。

**BOM**:¥15(4 个无源元件)

### 5.2 Stage 2: 可切换 SAW BPF 组(Phase 0 实测后决定)

仅当 Phase 0 测出 LNA 饱和或目标 SNR < 10 dB 时上。

**4 段 SAW 滤波器** + Peregrine PE42423 SP4T 开关:

| 段 | 中心 | 推荐 SAW 型号 | 插损 | 阻带抑制 |
|---|---|---|---|---|
| Band 1 | 200 MHz | Murata SAFEB200MAF0F | 2.5 dB | 40 dB |
| Band 2 | 450 MHz | Murata SAFEA450MAA0F | 3.0 dB | 45 dB |
| Band 3 | 900 MHz | Murata SAFFB942MAA0F | 2.8 dB | 42 dB |
| Band 4 | 1500 MHz | 无标准 SAW, 自研 LC BPF | 4 dB | 35 dB |

**RF 开关**:PE42423,DC – 6 GHz,IL < 0.7 dB,隔离 > 50 dB

**Stage 2 BOM**:¥350(4 SAW + 开关 + 偏置)

**Phase 0 实测决策门**(写进提案):
- 上 BPF 的触发条件:LNA 输出端在 100M-1G 测得带外干扰功率 > -30 dBm
- 不上 BPF 的依据:Pluto SDR 数字下变频已经提供 56 MHz 选频性,足够多数场景

### 5.3 阻抗匹配

信号链:CT 二次侧 → DC 隔直 → HPF 输入 → HPF 输出 → BPF 输入 → BPF 输出 → LNA 输入

每一段都是 50Ω 系统。

**关键节点的失配风险**:
- HPF 出口到 BPF 入口 / LNA 入口的过渡区
- 走线长度尽量短(< 10mm @ 1 GHz)
- 必要时加 π 型衰减器(0-3 dB)用 SNR 换匹配

## 六、级联频率响应分析

整条信号链的累计损耗/增益(假设 DUT 共模电流 10 μA @ 200 MHz):

| 节点 | 该级损耗/增益 | 累计电平 |
|---|---|---|
| DUT 电源线共模电流 | — | 10 μA |
| CT 一次侧 → 二次侧 | -23 dB | -77 dBm |
| TVS + DC 隔直 + 走线 | -0.5 dB | -77.5 dBm |
| Stage 1 HPF(通带) | -0.5 dB | -78 dBm |
| Stage 2 BPF(若启用) | -3 dB | -81 dBm |
| **LNA 输入** | — | **-78 ~ -81 dBm** |
| LNA(ERA-4SM+ × 2) | +28 dB | -50 ~ -53 dBm |
| Phase 1 加第三级 PGA-103+ | +20 dB | -30 ~ -33 dBm |
| **Pluto ADC 输入** | — | **-30 ~ -53 dBm** |

**Pluto AD9363 灵敏度**:典型 -85 dBm @ 56 MHz BW(数字下变频后噪底)

**信噪余量**:32-55 dB(取决于是否启用 BPF 和第三级 LNA)

**结论**:链路余量充足,Phase 0 即使用现成 LNA(无第三级)也能跑。
