## 一、架构修正:两条独立路径

Day 1 决策里保护链描述成 `GDT → MOV → 共模扼流 → ... → CT → LNA`,这隐含假设是**设备和市电串联**(plug-in 形态)。Route A 便携集成式需要**重新分清两条独立路径**:

### 路径 A:设备自己的电源

> 从墙插取电给 Pluto / CM4 等内部电路

```
外置 AC-DC 适配器 → 隔离 → 内部 +5V
```

GDT / MOV / 共模扼流圈 都在这条路径上(**标准 AC-DC 适配器设计**)。

### 路径 B:信号路径

> 夹式 CT 探测被测设备的电源线

```
被测设备电源线 ╳ 夹式 CT 磁芯 → 二次侧 → LNA
```

**关键洞察**:信号侧根本不接触市电,**保护需求大幅简化**。

### 修正结论

**Route A 用夹式 CT 后,信号路径上不需要 GDT/MOV**。这两个元件只在 Phase 2 插头适配形态下才需要。

这一修正让 Phase 1 设计简化、安全性提高、BOM 降低。

## 二、最终架构(Phase 1 Route A)

```
[被测设备 220V 电源线]
       │
       │ (穿过)
       ▼
   ╔══════╗ 夹式宽带 CT
   ║ ███  ║ 一次侧(电源线)无电气连接
   ║ ███  ║ 二次侧(5-7 匝绕组)
   ╚══┬═══╝
      │ SMA 同轴(50Ω 阻抗匹配)
      ▼
  ┌─────────────────┐
  │ ESD/瞬态保护    │ Bourns CDSOT23-T05LC TVS 阵列
  │ (低电容)        │ 钳位 ±5V,C<1pF @ 1GHz
  └────────┬────────┘
           │
  ┌────────▼────────┐
  │ DC 隔直          │ Murata GRM18 NP0 1nF/100V
  │                  │ 串联模式
  └────────┬────────┘
           │
  ┌────────▼────────┐
  │ Stage 1: LC HPF │ 4 阶 Butterworth, fc=30 MHz
  │ (永远在线)       │ C1=150pF, L2=150nH, C3=56pF, L4=330nH
  │                  │ 通带损耗 <1 dB,50Hz 抑制 >100 dB
  └────────┬────────┘
           │
  ┌────────▼────────┐
  │ Stage 2: BPF 组 │ 可选,4 段 SAW + PE42423 SP4T 开关
  │ (Phase 0 决定)  │ 200/450/900/1500 MHz
  └────────┬────────┘
           │
  ┌────────▼────────┐
  │ LNA(候选人 BYO)│ ERA-4SM+ × 2,实测 +28 dB
  │                  │ Phase 1 加 PGA-103+ 第三级 → ~50 dB
  └────────┬────────┘
           │
           ▼ 至 Pluto SDR RX
```

设备自己的电源路径在物理上**完全独立** — 通过外置 Mean Well IRM-10-5 适配器从墙插取电,然后内部 LDO / 开关电源分配。这部分是标准嵌入式系统电源设计,不放在 Ch2 范围内。

## 三、耦合 — 宽带夹式 CT 设计

这是整个项目最难的硬件单元。

### 3.1 关键设计参数

| 参数 | 目标 | 备选 | 说明 |
|---|---|---|---|
| **-3 dB 带宽下限** | 1 MHz | 500 kHz | 不需要更低(目标 ≥155 MHz) |
| **-3 dB 带宽上限** | 1 GHz | 500 MHz | 1 GHz 难,500 MHz 足够覆盖 Table II 7/12 设备 |
| **插损平台** | -30 dB | -45 dB | 越低越好,但实物难 < -25 dB |
| **平坦度** | ±3 dB | ±5 dB | 跨工作带 |
| **耐压** | 250 V AC 50 Hz | — | 一次侧穿芯,标称耐压由磁芯绝缘决定 |
| **物理尺寸** | OD<25 mm | OD<40 mm | 适配紧凑外壳 |
| **形态** | **穿芯式**(不分体) | 分体钳形(Phase 2) | 分体钳形高频性能严重下降 |

### 3.2 磁芯选型 — 复合材质串叠

单一磁材无法做到 1 MHz – 1 GHz 平响,**用 2 个不同材质叠加**:

```
        ╭─────────╮  顶层:Fair-Rite 2675102002
        │ ████████│  材质 #75(Nano-crystalline),μᵣ ~ 5000
        │  ▒ ▒ ▒  │  覆盖低端 1-50 MHz
        │ ████████│
        ├─────────┤
        │ ████████│  底层:Fair-Rite 2643000201
        │  ▒ ▒ ▒  │  材质 #43(NiZn),μᵣ ~ 800
        │ ████████│  覆盖中段 50 MHz – 500 MHz
        ╰─────────╯  
        外径 12.7 mm,内径 7.9 mm,各 H=6.35 mm
        合计高度 12.7 mm
```

**复合堆叠**的原理:

两个磁材的频响曲线**互补叠加**,有效频响 = 两段并联响应。

- 1 MHz – 50 MHz 段 #75 主导
- 50 – 500 MHz 段 #43 主导
- \>500 MHz 段已经进入磁芯非主响应区,只能靠"空气芯效应"(漏感主导)勉强保留耦合

**BOM 成本**:¥60(两片磁芯)

### 3.3 绕组设计

```
┌─────────────────────────────────────────┐
│  绕组方式:5 匝单层 Teflon 同轴内导体    │
│                                          │
│  线材选择(关键):                       │
│  - RG-178 内导体(剥外层,只用内导体    │
│    + Teflon 内绝缘)                      │
│  - 介电常数 εr=2.1,匝间分布电容低       │
│  - 直径 ~0.6mm,绕组紧凑                 │
│                                          │
│  绕法:                                   │
│  - 单层均匀分布(360° 间隔均匀)         │
│  - 起头和收尾点距离 ≥1/4 周长(防止     │
│    自感互耦)                             │
│  - 不要扎在一起!                         │
└─────────────────────────────────────────┘
```

**为什么是 5 匝**:

| 匝数 | 灵敏度 | 上限频率 | 评价 |
|---|---|---|---|
| 1-2 匝 | 低 | 高 | 信号太弱 |
| 5-7 匝 | 中 | 500 MHz – 1 GHz | ✅ **甜区** |
| >10 匝 | 高 | 100-200 MHz | 自谐振点太低 |

5-7 匝是经验甜区:匝间分布电容 Cₚ 和漏感 Lₗ 形成的自谐振点通常落在 500 MHz – 1 GHz。

### 3.4 灵敏度计算

二次侧电压:

```
V₂ = (Iₚ × Z_load) / N
```

- N = 5 匝
- Z_load = 50 Ω
- 假设 Iₚ = 1 mA(目标频段共模电流):V₂ = 10 mV = -27 dBm
- 实际目标信号 1-100 μA 量级:V₂ = 0.01-1 mV = **-67 ~ -47 dBm**

这给 LNA 提供了估算的输入功率范围。

### 3.5 输出端接 + 屏蔽

```
[CT 二次绕组] ──短引线── [50Ω SMD 电阻 0805] ── SMA 母座
                  │
                  └──→ 同时焊在 PCB 上
                       (引线长度 < 5 mm)
```

**关键点**:
- 50Ω 端接电阻**就近**焊在 CT 引脚根部,不要拉长线再接
- 长引线 = 反射 = 高频驻波 = 性能下降
- 选 0805 薄膜电阻(±1%),寄生电感 < 0.5 nH

**屏蔽外罩**:
- 整个 CT 装在**金属罩**(铜或铝)内,罩开两个孔让电源线穿过
- 罩接信号地(单点接地)
- 作用:屏蔽外部空间辐射对 CT 的串扰(否则空间 WiFi/GSM 直接耦合进绕组)

### 3.6 预期性能(基于经验估算,需 VNA 验证)

| 频率 | 预期插损 | 备注 |
|---|---|---|
| 1 MHz | -25 dB | #75 磁芯主导 |
| 10 MHz | -22 dB | #75 工作峰区 |
| 100 MHz | -23 dB | #43 主导 |
| 500 MHz | -25 dB | #43 衰减开始 |
| 1 GHz | -30 ~ -35 dB | 漏感主导,边缘可用 |
| 2 GHz | -40 ~ -50 dB | 性能恶化,不可用 |

**核心断言**:**1 MHz – 800 MHz 可用,1 GHz 边缘可用,>1 GHz 失效**。这覆盖 EM Eye Table II 中**至少 9/12 设备**的目标频点。

## 四、信号侧保护(简化版)

### 4.1 TVS 阵列(替代 GDT+MOV)

**为什么不用 GDT/MOV?**

| 元件 | 寄生电容 | 高频影响 |
|---|---|---|
| GDT | ~1 pF | 影响小,可接受 |
| MOV | 200-500 pF | ❌ **严重影响高频通带** |

更关键的是:GDT/MOV 主要用于市电直接侵入(雷击、浪涌),夹式 CT 本身就是**电气隔离**的,**没有这种威胁**。

**选型**:**Bourns CDSOT23-T05LC**

| 参数 | 值 |
|---|---|
| 类型 | 低电容 TVS 阵列 |
| 寄生电容 | <1 pF @ 1 GHz |
| 钳位电压 | ±5 V |
| 响应时间 | < 1 ns |
| 保护对象 | CT 二次侧 ESD(手触摸)+ DUT 启动瞬态 |

### 4.2 DC 隔直

**选型**:Murata GRM18 系列 NP0/C0G 1 nF 100V

| 频率 | 容抗 | 评价 |
|---|---|---|
| 1 MHz | 160 Ω | 可通,稍有损耗 |
| 100 MHz | 1.6 Ω | 透明 |
| 1 GHz | 0.16 Ω | 透明 |

NP0 材质温漂极小,Q 值高。

### 4.3 ESD 防护策略

夹式 CT 二次侧 SMA 接头是 ESD 入口,**TVS 直接放在 SMA 接头到 PCB 路径上**,距离 < 5 mm。

## 五、滤波 — 两阶段策略

### 5.1 Stage 1: LC HPF(永远在线)

**目的**:滤掉 AM 广播(<2 MHz)+ FM 广播低端 + 室内 SMPS 传导 EMI(<30 MHz)

**拓扑**:**4 阶 Butterworth HPF, 50Ω, fc=30 MHz**

```
   ┌── L2 ──┬── L4 ──┐
50Ω        │        │     50Ω
in ─[C1]─ GND ─[C3]─GND ─ out
```

**元件清单**:

| 位号 | 值 | 型号 | 说明 |
|---|---|---|---|
| C1 | 150 pF | Murata GRM1885C2A151JA01 | NP0 |
| L2 | 150 nH | Coilcraft 0603HP-151X | Q>50 @ 100MHz |
| C3 | 56 pF | Murata GRM1885C2A560JA01 | NP0 |
| L4 | 330 nH | Coilcraft 0603HP-331X | — |

**理论性能**:

| 频率 | 损耗 |
|---|---|
| 50 Hz | -200 dB |
| 1 MHz | -100 dB |
| 10 MHz | -25 dB |
| 30 MHz | -3 dB (截止) |
| 100 MHz | -0.3 dB |
| 1 GHz | -0.1 dB |

**通带损耗 < 1 dB**,这是 Stage 1 必选的关键理由 —— 几乎不付代价就拿到 100 dB 的低频抑制。

**BOM**:¥15(4 个无源元件)

### 5.2 Stage 2: 可切换 SAW BPF 组(Phase 0 实测后决定)

仅当 Phase 0 测出 LNA 饱和或目标 SNR < 10 dB 时上。

**4 段 SAW 滤波器** + Peregrine PE42423 SP4T 开关:

| 段 | 中心 | 推荐 SAW 型号 | 插损 | 阻带抑制 |
|---|---|---|---|---|
| Band 1 | 200 MHz | Murata SAFEB200MAF0F | 2.5 dB | 40 dB |
| Band 2 | 450 MHz | Murata SAFEA450MAA0F | 3.0 dB | 45 dB |
| Band 3 | 900 MHz | Murata SAFFB942MAA0F | 2.8 dB | 42 dB |
| Band 4 | 1500 MHz | 无标准 SAW, 自研 LC BPF | 4 dB | 35 dB |

**RF 开关**:PE42423,DC – 6 GHz,IL < 0.7 dB,隔离 > 50 dB

**Stage 2 BOM**:¥350(4 SAW + 开关 + 偏置)

**Phase 0 实测决策门**(写进提案):
- 上 BPF 的触发条件:LNA 输出端在 100M-1G 测得带外干扰功率 > -30 dBm
- 不上 BPF 的依据:Pluto SDR 数字下变频已经提供 56 MHz 选频性,足够多数场景

### 5.3 阻抗匹配

信号链:CT 二次侧 → DC 隔直 → HPF 输入 → HPF 输出 → BPF 输入 → BPF 输出 → LNA 输入

每一段都是 50Ω 系统。

**关键节点的失配风险**:
- HPF 出口到 BPF 入口 / LNA 入口的过渡区
- 走线长度尽量短(< 10mm @ 1 GHz)
- 必要时加 π 型衰减器(0-3 dB)用 SNR 换匹配

## 六、级联频率响应分析

整条信号链的累计损耗/增益(假设 DUT 共模电流 10 μA @ 200 MHz):

| 节点 | 该级损耗/增益 | 累计电平 |
|---|---|---|
| DUT 电源线共模电流 | — | 10 μA |
| CT 一次侧 → 二次侧 | -23 dB | -77 dBm |
| TVS + DC 隔直 + 走线 | -0.5 dB | -77.5 dBm |
| Stage 1 HPF(通带) | -0.5 dB | -78 dBm |
| Stage 2 BPF(若启用) | -3 dB | -81 dBm |
| **LNA 输入** | — | **-78 ~ -81 dBm** |
| LNA(ERA-4SM+ × 2) | +28 dB | -50 ~ -53 dBm |
| Phase 1 加第三级 PGA-103+ | +20 dB | -30 ~ -33 dBm |
| **Pluto ADC 输入** | — | **-30 ~ -53 dBm** |

**Pluto AD9363 灵敏度**:典型 -85 dBm @ 56 MHz BW(数字下变频后噪底)

**信噪余量**:32-55 dB(取决于是否启用 BPF 和第三级 LNA)

**结论**:链路余量充足,Phase 0 即使用现成 LNA(无第三级)也能跑。

## 七、PCB 布局策略

```
                ┌──── 80 mm ────┐
              ┌─┴───────────────┴─┐
              │                    │ ↑
   电源/数字 │  数字域(右半)    │ 6
   接口区     │  Pluto + CM4 + WiFi│ 0
              │                    │ m
              │ ╔══════════════╗   │ m
              │ ║ 共地隔离条   ║   │
              │ ╚══════════════╝   │
              │                    │
   信号接入 ┌─┤  模拟域(左半)    ├─┐
   SMA      │ │  CT─TVS─HPF─BPF─   │ │ ↓
            │ │  ─LNA              │ │
              └────────────────────┘
```

**4 层 PCB 叠层**:

| 层 | 用途 | 材质 |
|---|---|---|
| L1 | 信号 | Rogers RO4350B,εr=3.66 @ 1GHz |
| L2 | 接地平面(全填铜) | FR-4 |
| L3 | 电源平面(分模拟/数字两区) | FR-4 |
| L4 | 数字信号 | FR-4 |

**关键设计**:
- 模拟域整体加铜罩屏蔽
- LNA 单独子腔体加屏蔽
- 数字/模拟域接地仅在一点(Star Ground)

## 风险标注

> 本文档基于工程经验估算,**所有性能数字都需要 Phase 0 阶段 VNA 实测验证**。
> 特别是:
> - 复合磁芯(#75 + #43)在 >300 MHz 的实际叠加行为可能与简单加和不同
> - 5 匝绕组的自谐振点取决于具体绕法和介质,可能与估算偏差 ±30%
> - 夹式 CT 形态(穿芯式)在最终装配时要兼顾"操作方便"和"几何精度",这是一个待权衡的工程取舍点
