## 一、量化分析

### 1.1 磁通密度与饱和检查

**问题**:CT 一次侧是高电流电源线(0.5 – 10 A AC),会不会让磁芯饱和?

#### 工频情况
L+N 同向穿芯下,DM 完全抵消,理论净磁通 = 0。实际几何不对称导致 DM 残留约 30 dB:
- 设备工作电流 1 A AC(典型)
- DM 抑制 30 dB → 等效净电流 32 mA
- 50 Hz 下磁感应强度 B = μᵣ·μ₀·N·I / l_path

对 Fair-Rite #43 磁芯:
- μᵣ ≈ 800(50 Hz – 1 MHz 段)
- N = 1(一次侧穿芯)
- l_path = π·(OD+ID)/2 = π·10.3 mm = 32.4 mm
- B = 800 × 4π×10⁻⁷ × 1 × 0.032 / 0.0324
- B ≈ 0.001 T = **1 mT**

Fair-Rite #43 的饱和磁感应 **B_sat ≈ 0.27 T @ 25°C**(数据手册值)。

**结论**:工频残留电流的磁通密度 = 0.001 T,远低于饱和点 0.27 T,**安全余量 270×**。

#### 浪涌瞬态情况
IEC 61000-4-5 浪涌测试:6 kV / 3 kA 1.2/50 μs 脉冲。

**关键判断**:浪涌发生在 DUT 电源接入端,**穿芯式 CT 一次侧无电气连接**,浪涌只在 DUT 内部传导,**不会通过 CT 一次侧**。

CT 看到的是浪涌瞬间的**共模电流分量**,由 DUT 寄生回路决定,典型 < 1 A 量级。即使按最坏情况 1 A 持续 50 μs,产生的瞬态磁通也远低于饱和点。

**结论**:磁芯不会因正常使用或浪涌而饱和。

### 1.2 自谐振频率(SRF)精确估计

**问题**:5 匝绕组的自谐振点在哪里?这决定 CT 的高频上限。

#### 线圈自感(空气芯近似)
高频时磁芯磁导率 μᵣ → 1(进入空气芯区),可按空气芯电感公式估算:

```
L_self ≈ N² · μ₀ · π · r_avg² / l_path
```

其中:
- N = 5
- r_avg = (OD+ID)/4 = (12.7+7.9)/4 = 5.15 mm = 0.515 cm
- l_path = π·(OD+ID)/2 = 32.4 mm

代入:
```
L_self = 25 × (4π×10⁻⁷) × π × (5.15×10⁻³)² / (32.4×10⁻³)
      ≈ 81 nH
```

#### 匝间分布电容
Teflon 介质(εr = 2.1),5 匝单层均匀绕,相邻匝间距 ~2 mm:
- 每对相邻匝形成平行板电容(近似):C ≈ 1-3 pF
- 5 匝有 4 对相邻匝,加上对地电容(磁芯、PCB、SMA 接头)
- C_total 估计:**5 – 10 pF**

#### 自谐振频率
```
f_SRF = 1 / (2π · √(L · C))
```

| L (nH) | C (pF) | f_SRF (MHz) |
|---|---|---|
| 81 | 5 | **791** |
| 81 | 10 | **560** |
| 50(紧绕) | 3 | **1300** |
| 100(松绕) | 12 | **460** |

**结论**:SRF 估计区间 **460 – 1300 MHz**,典型 600-800 MHz。这是 §3.56 列"自谐振点过低"为风险的依据,**VNA 实测必查**。

#### 优化建议
如果 VNA 实测 SRF < 500 MHz:
- 方案 A:降到 3 匝(L 降到 ~30 nH,SRF 提到 ~1.2 GHz),代价是灵敏度损失 4.4 dB(20·log(5/3))
- 方案 B:松绕(增加匝间距到 3-4 mm),C 降到 3-5 pF,SRF 提到 800 MHz+,代价是物理尺寸增大

### 1.3 二次侧阻抗与 VSWR

**问题**:LNA 看到的 CT 输出阻抗是多少?会不会失配?

#### 理想 CT 二次侧阻抗
理想情况:二次侧反射阻抗 = 50Ω(端接电阻),从 LNA 看过去是完美匹配。

#### 实际等效模型
```
       CT 二次侧
   ─────┬────────┬─────
        │        │
   [L_l]│        │[L_m]
        │        │
   ─────┴────────┴─────
        │
   ─────┤
        ├──[R_load=50Ω]──
   ─────┤
```

- L_m(磁化电感):并联,影响低频
- L_l(漏感):串联,影响高频
- C_w(分布电容):并联,与 L_l 形成自谐振

#### 反射阻抗仿真(粗略计算)

| 频率 | Z_secondary(估算) | VSWR(对 50Ω) | 评价 |
|---|---|---|---|
| 1 MHz | 50 + j5 Ω | 1.10 | 优 |
| 10 MHz | 50 + j2 Ω | 1.04 | 优 |
| 100 MHz | 50 + j1 Ω | 1.02 | 优 |
| 500 MHz | 50 + j8 Ω | 1.17 | 优 |
| 1 GHz | 50 + j30 Ω | 1.85 | 可接受 |
| 1.5 GHz | 70 - j40 Ω | 2.5 | 差(信号严重失配) |

**结论**:工作带 100 MHz – 1 GHz 内 VSWR < 2:1,ERA-4SM+ 输入端可接受。**>1.2 GHz 性能恶化**,但论文 Table II 多数目标在此范围以下。

### 1.4 DM 抑制比预算

**问题**:实际 DM 抑制能达到多少 dB?足够压制 50 Hz 工频吗?

#### 不对称源分析

| 误差源 | 典型不对称量 | DM 抑制损失 |
|---|---|---|
| L 和 N 在磁芯窗口内的位置偏差 | ±0.5 mm(12.7 mm OD) | -25 dB(从理论 ∞ 降到 30-40 dB) |
| 线径差异(L 和 N 用不同标定线材) | 20% 差异 | -5 dB |
| 磁芯不均匀(制造公差) | μᵣ 局部 ±10% | -3 dB |
| 二次侧绕组对称性 | 5 匝同心 | -2 dB |
| **预期总 DM 抑制** | | **30-40 dB** |

#### 工频残留计算

| 阶段 | 信号水平 |
|---|---|
| DUT 工作电流(50 Hz DM) | 1 A AC(典型家电) |
| 经 CT(30 dB DM 抑制) | 32 mA 等效一次电流 |
| CT 二次侧(转换比 5:1, 50Ω 端接) | V₂ = 50 × 0.032 / 5 = 0.32 V_rms |
| 等效功率(50Ω) | 0.32² / 50 = 2 mW = **+3 dBm** |
| 经 LC HPF(30 MHz 截止,50 Hz 处衰减 -100 dB) | -97 dBm |

**结论**:工频残留经 HPF 后 -97 dBm,**远低于 LNA 噪底**,完全不构成饱和或干扰威胁。

### 1.5 频响仿真预期

用简化等效模型在 LTSpice 跑一遍(实际未跑,这里只列预期曲线):

```
等效 CT 模型:
  - L_m = 100 μH(磁芯主导,#75 + #43 复合)
  - L_l = 50 nH(漏感)
  - C_w = 5 pF(分布电容)
  - R_load = 50Ω
  - 一次侧:理想电流源 I_p
  - 二次侧:N=5 匝
```

预期 S21 曲线(转换增益 = -20·log(N) - 损耗):

| 频率 | 理论 S21(dB) | 实测预期(含损耗)|
|---|---|---|
| 100 kHz | -∞(磁化电感短路) | < -50 |
| 1 MHz | -14 | -25 |
| 10 MHz | -14 | -22 |
| 100 MHz | -14 | -23 |
| 500 MHz | -14 | -25(开始衰减) |
| 800 MHz | -14 | -30(显著衰减) |
| 1 GHz | -14 | -35(漏感主导) |
| 自谐振点 | 凸起或凹陷 | 可能 ±5 dB 跳变 |

**关键观察**:理论转换损耗 -14 dB(由 N=5 决定),实际加上磁芯损耗、漏感、寄生电容等,合计 -25 ~ -30 dB 平台插损。

## 二、替代方案对比

### 2.1 全方案对比表

| 方案 | 频段 | 灵敏度 | 安全 | 体积 | 成本 | 评分 |

| Rogowski 线圈 | 100k-100M | 低 | 高 | 中 | ¥80 | ⭐⭐ |

### 2.2 为什么放弃其他方案

**电容耦合(¥10 看起来很诱人,但拒绝)**:
- 电容串接在 220V 火线上,如果失效短路,**220V 直接进入采集系统** → 致命
- 即使用 X1/Y1 安全电容(额定 250V AC,瞬态 2.5 kV),失效模式仍存在
- Y2 电容(漏电流要求严格)在高频下寄生振荡严重
- 工程结论:不值得为 ¥50 的成本节省承担触电风险

**Rogowski 线圈(柔性,可弯曲)**:
- 原理:空气芯,通过 dI/dt 测电流
- 优势:不饱和,适合大电流测量
- 劣势:带宽典型 100 kHz – 100 MHz,**完全不够覆盖我们 100 MHz – 1 GHz 目标**
- 高频段衰减严重,无法用

**H 场近场探头(Beehive 100C / Aaronia 等)**:
- 非接触式,贴在电缆外探测磁场
- 优势:不需要破坏电缆,装拆方便
- 劣势 1:灵敏度强烈依赖距离和方向,**实验重复性差**
- 劣势 2:接收的是辐射场,**和我们要的传导电流不直接对应**
- 适合调试和定性观察,**不适合定量测量和生产部署**

**直接电阻分压**:
- 把火线接到一个高阻分压器,二次侧给 LNA
- 优势:平坦响应 DC-GHz
- 劣势:**直接电气连接到 220V,一次失误就出事**
- 工程结论:不可接受

**商用 LISN(50/250 µH 标准网络)**:
- EMC 测试标准设备,频段 9 kHz – 30 MHz(CISPR 16 标准)
- 优势:阻抗标准化,结果可复现
- 劣势 1:**30 MHz 上限完全不够**(我们要 100 MHz – 1 GHz)
- 劣势 2:体积大(典型 200×100×100 mm),不便携
- 劣势 3:价格高(¥8000+)
- **完全不适合本项目**(虽然 PI 团队可能在 Phase 0 借用作为对比基准)

### 2.3 复合磁芯 CT 的工程优势(再确认)

- ✅ **频段** 1 MHz – 800 MHz 覆盖 EM Eye Table II **多数目标频点**
- ✅ **安全性最高**(完全电气隔离,无任何电容/电阻接触市电的失效路径)
- ✅ **体积小**(OD 12.7 mm 磁芯 + 5 匝绕组,总体积 < 1 cm³)
- ✅ **自研可行**(BOM ¥60,装配 1-2 天,无需特殊设备)
- ✅ **可量产化**(磁芯标准件,绕组可机械化)
- ⚠️ **风险 1**:自谐振点不确定(VNA 实测必查)
- ⚠️ **风险 2**:DM 抑制依赖几何对称(需 2 芯延长线工装保证)

### 4.2 注入电流校准

用已知电流验证 CT 的转移系数(灵敏度)。

#### 测试设置

```
信号发生器 ────[50Ω 输出阻抗]───── 50Ω 串联电阻 ────→ 单根线穿过 CT
                                                            │
                                                            │
                                                            └──→ 信号源地

CT 二次侧 ──→ 频谱仪(或 LDSDR)
```

#### 理论计算

- 信号发生器输出 V_signal = 0 dBm = 224 mVrms
- 输出端有 50Ω 内阻 + 50Ω 串联电阻 = 100Ω 回路阻抗
- 注入到 CT 一次侧的电流 I_p = V_signal / 100Ω = 2.24 mA rms

CT 二次侧输出电压:
- N = 5 匝
- R_load = 50Ω
- 理想:V₂ = R_load × I_p / N = 50 × 0.00224 / 5 = 22.4 mV rms
- 等效功率:V₂² / 50 = (0.0224)² / 50 = 10 μW = **-20 dBm**

**理论 S21**:
- 二次侧 -20 dBm,一次侧输入 0 dBm → S21_理论 = -20 dB

#### 实测对比

| 频率 | S21_理论 | S21_实测 | 偏差 | 说明 |
|---|---|---|---|---|
| 100 kHz | -20 dB | -45 dB | -25 dB(异常)| 磁化电感不足,正常 |
| 1 MHz | -20 dB | -25 dB | -5 dB | 磁芯小损耗,合理 |
| 100 MHz | -20 dB | -23 dB | -3 dB | 工作带,优 |
| 1 GHz | -20 dB | -32 dB | -12 dB | 接近 SRF,衰减加剧 |

**关键观察**:工作带(10 MHz – 500 MHz)内偏差 < 5 dB,说明 CT 工作正常。

#### 转移系数标定

每个工作频率上记录 S21 实测值,作为后续整链增益计算的标定基准。例如:
- 100 MHz:转移系数 = -23 dB
- 在该频段使用时,LDSDR 看到 -50 dBm → 实际一次侧电流 = -50 + 23 - 28(LNA 增益)= -55 dB 等效

## 五、失效模式与诊断

### 5.1 用户错误穿芯

工装设计已经强制限制 L+N 同向穿芯 + PE 旁路,**用户在正常使用下无法误操作**。但需考虑工装拆机维修后的错误重组:

| 错误穿法 | CT 看到 | 现象 | 诊断 |
|---|---|---|---|
| 只穿 L(N 在外) | I_DM + I_CM/2 混合 | 50 Hz 巨大,即使 HPF 也压不住 LNA 输入 | LNA 输入近 0 dBm,P1dB 边缘 |
| 只穿 N | 同上 | 同上 | 同上 |
| L+N+PE 全穿 | 三线 CM 之和 = 0 | 频谱基本是噪底,无目标信号 | GNURadio 任何频段都看不到信号 |
| L+N 反向穿 | 2·I_DM | 50 Hz 仍巨大,目标频段噪底 | HPF 后 LNA 输入仍超标,但与"只穿 L"略不同 |

**对策**:工装组装时用机械限位 + 标识 + 装配工艺单。

### 5.2 磁芯位移

如果 CT 在使用过程中磁芯松动(被振动、跌落、温度循环):
- **现象**:S21 频响曲线变形,自谐振点漂移
- **典型表现**:200-400 MHz 段出现 5-10 dB 的凹陷或突起
- **诊断**:取出工装,VNA 复测,与出厂值对比
- **对策**:磁芯用环氧或硅胶固定到工装外壳,不允许任何相对运动

### 5.3 二次侧故障

| 故障 | 现象 | 诊断 |
|---|---|---|
| SMA 输出对地短路 | CT 完全无输出,LNA 入端 0 信号 | 用万用表测 SMA 中心针到外壳电阻,应为 50Ω |
| SMA 输出开路 | LNA 输入悬空,噪底异常大,可能自激 | 同上,电阻应为 50Ω 不是 ∞ |
| 50Ω 端接电阻烧毁 | 输出阻抗变高,LNA 看到失配 | 用 VNA 测 S11,应 < -10 dB |
| 绕组断裂(隐性) | 输出间歇性,温度敏感 | 用 VNA 长时间稳定性测试,或弯折工装应力测试 |

### 5.4 ESD 后性能漂移

如果 TVS(CDSOT23-T05LC)多次触发 ESD 后老化:
- **现象 1**:寄生电容增加(0.5 pF → 2 pF),>1 GHz 段插损增加 3-5 dB
- **现象 2**:钳位电压漂移(±5 V → ±6 V),保护能力下降
- **现象 3**:漏电流增加,LNA 噪底略升

**检测方法**:
- 用静电枪做 ±8 kV 接触放电测试,记录 100 次后的 S21 变化
- 如果工作带性能下降 > 3 dB,**更换 TVS**

**对策**:在工装维护周期(每 6 个月)内,做一次 VNA 复测和 TVS 替换。

## 六、章节总结(写进 Ch2 的核心要点)

### 给提案 Ch2 用的 5 句核心断言

1. **CT 选型**:Fair-Rite #75 + #43 复合磁芯 + 5 匝 Teflon 绕组,工作带 1 MHz – 800 MHz,插损 -25 dB ± 5 dB 平台。

2. **DM 抑制**:L+N 同向穿芯结构,理论 ∞ dB,实际 30-40 dB(限制因素是几何对称度),工频 50 Hz 残余经 HPF 后 -97 dBm,完全无害。

3. **自谐振点**:估算 600-800 MHz,VNA 实测必查;若 < 500 MHz,降到 3 匝迭代。

4. **替代方案**:电容耦合不安全,Rogowski 带宽不够,LISN 体积过大,H 场探头重复性差 → CT 是唯一兼顾安全性、带宽、体积、成本的方案。

5. **2 芯延长线工装**:¥170 单件成本,机械保证 L+N 同向穿芯 + PE 旁路,用户无学习成本,**零误操作风险**。

### Phase 0 验证检查清单

- [ ] CT 单独 VNA 测试,S21 平台 -25 dB ± 5 dB,SRF > 600 MHz
- [ ] 前端板单独 VNA 测试,通带损耗 < 2 dB,带外抑制 > 30 dB
- [ ] 整链(CT + 前端板)注入校准,LDSDR 能观测 -40 dBm 信号
- [ ] DUT(RPi 4B + Cam V1)真实信号,在 204 MHz 看到 30 Hz 周期信号
- [ ] 摄像头开关对比,信号差 > 10 dB → **Phase 0 Go**
